# Combat Studio Readiness Matrix

This milestone will measure generated dataset availability, field coverage, identity integrity, and explicit-ID join coverage for items, equipment, weapons, requirements, combat profiles, monsters, and quests.

Guardrails: missing datasets are not empty datasets; field presence is not factual correctness; ID joins do not prove quest unlock eligibility; unknown values must remain unknown. The audit is not a DPS engine and does not claim complete OSRS coverage.
